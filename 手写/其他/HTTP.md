### HTTP 版本

HTTP/0.9 单行协议
* 只有GET 请求，无请求头和请求体
* 只能传输 HTML 文件，以ASCII 字符流返回
* 无响应头

HTTP/1.0 多类型支持
* 支持多种文件类型传输，不限于ASCII 编码
* 引入请求头和响应头
* 每个请求都需要建立新的TCP 连接

HTTP/1.1 持久连接
* 引入持久链接(keep-alive)： 一个TCP 链接可以传输多个HTTP请求
* 默认开启，支持6～8并发
* 存在对头堵塞问题，前面的请求会堵塞后续请求
* 引入HOST 字段，支持虚拟主机
* 引入Chunk transfer 机制处理动态内容长度

HTTP/2.0 多路复用
* 一个域名只使用一个TCP 长连接
* 引入二进制分帧层，实现多路复用
* 可对请求设置优先级
* 支持TLS 对称加密

HTTP3.0 QUIC 协议
* 基于UDP 而非TCP
* 解决TCP 对头堵塞问题


### HTTP 状态码
200 成功

301 资源永久重定向
302 资源零食重定向
304 协商缓存

400 请求错误
401 请求没有携带认证信息
403 禁止访问
404 找不到资源
500 服务错误

### JWT
组成
  * Header 加密算法和令牌类型
  * payload 数据
  * signature 签名，验证前面两部份没有被篡改
